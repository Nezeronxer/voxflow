# VoxFlow v2.4.3 — обработка текста любыми моделями OpenRouter, плашка показывает итог

Релиз поверх 2.4.2.

## Любые модели OpenRouter для обработки текста

В «Обработке текста» → «Нейросеть» → OpenAI-совместимый → OpenRouter теперь виден весь каталог текстовых
моделей, а не только бесплатные: сначала рекомендованная, дальше от дешёвых к дорогим, с ценой за миллион
токенов. Для правки диктовки хватает самых дешёвых, одна диктовка стоит сотые доли цента. Ключ - свой:
создайте его на openrouter.ai/keys и вставьте в поле «API-ключ», он хранится только на вашем компьютере.
Рекомендуем Claude Haiku 5.5: дешёвая, не теряет слов и не вырезает ругательства.

## Одинаково во всех программах

Текст обрабатывается одним правилом в любом окне - в мессенджере, терминале, браузере. Раньше облачная модель
меняла стиль в зависимости от программы (где-то убирала точку, где-то писала дословно).

## Плашка показывает то, что вставилось

После вставки плашка 2 секунды показывает готовый текст - с пунктуацией, исправлениями и абзацами, а не сырое
распознавание.

## Абзацы и скорость

Длинную диктовку из нескольких мыслей модель делит на абзацы. Соединение с OpenRouter открывается, пока вы
говорите, - готовый текст приходит быстрее.

## Окно плашки на Mac

Плашка больше не пропадает при смене рабочего стола и поверх полноэкранных приложений.

## Удалённая Whisper не скачивается снова

Если при языке «Авто» с GigaAM удалить модели Whisper, приложение больше не качает их заново при запуске.

Подробности - D-058…D-062 в DECISIONS.md.

# VoxFlow v2.4.2 — Ollama на Mac больше не забирает 5-6 ГБ памяти

Релиз поверх 2.4.1.

## Модель Ollama читается с диска, а не копируется в память

Когда свободной памяти на Mac было меньше, чем по прикидке нужно модели, Ollama
переставала читать её с диска по мере надобности и копировала целиком в оперативную
память. Для gemma4 e4b это 5,4 ГБ, и чем меньше было свободной памяти, тем больше
Ollama забирала. Теперь VoxFlow прямо просит Ollama читать модель с диска: та же модель
занимает около 0,5-1 ГБ, ответы не меняются. В 2.4.1 причина была описана неверно:
окно контекста экономит только около 200 МБ.

Подробности - D-057 в DECISIONS.md.

# VoxFlow v2.4.1 — локальная модель Ollama просит окно поменьше

Релиз поверх 2.4.0.

## Окно контекста Ollama

При обработке текста через Ollama VoxFlow просил у модели окно контекста на 16 тысяч
токенов, хотя фраза диктовки вместе с инструкциями занимает около 600. Теперь окно
начинается с 4 тысяч токенов и растёт только для длинной диктовки. Экономия - около
200 МБ. Главную причину большого расхода памяти чинит 2.4.2.

Подробности - D-056 в DECISIONS.md.

# VoxFlow v2.4.0 — приложение занимает меньше памяти, для Arch Linux есть свой пакет

Релиз поверх 2.3.5.

## Меньше памяти

Раньше распознавание речи держало в памяти около 2,5-3 ГБ и не отпускало их никогда. Теперь веса
моделей читаются прямо из файлов, и в работе уходит около 1,3 ГБ (пик во время диктовки), а после
загрузки - около 1 ГБ. После выгрузки моделей остаётся около 100 МБ. Тексты при этом не меняются: на 60
тестовых записях результат тот же буква в букву. Parakeet (английский) стал работать примерно на 14%
медленнее - цена за экономию памяти. На Windows чтение из файлов выключено, поэтому экономия там меньше:
её дают Parakeet и выгрузка в простое.

## Модели выгружаются в простое

Если вы не диктовали 10 минут, распознавание, голосовые модели и встроенный ИИ выгружаются из памяти.
Первая фраза после перерыва начнётся чуть позже, пока модель загрузится, но запись и текст не теряются.
В «Распознавании» можно поменять время или снять галочку - тогда модели будут держаться в памяти всегда,
как раньше. Во время записи и обработки фразы модели не выгружаются.

## Размер моделей и удаление

В разделе «Модели» у каждой модели виден размер на диске, а те, что сейчас не нужны, помечены «Не
используется». Ненужную модель можно удалить кнопкой в строке (с подтверждением) - она сразу уходит и из
памяти, и с диска.

## Linux: пакет для Arch

В релиз добавлен пакет `VoxFlow-2.4.0-linux-x64.pkg.tar.zst`. Установка:

```
sudo pacman -U VoxFlow-2.4.0-linux-x64.pkg.tar.zst
```

Если VoxFlow установлен таким пакетом, встроенное обновление само скачает новый пакет, проверит его
сумму и поставит через pacman (запросит пароль). Если система не может показать окно пароля, файл
сохранится, а приложение покажет команду `sudo pacman -U ...`. AppImage, deb, rpm, Windows и macOS
обновляются как раньше.

Подробности - D-053, D-054, D-055 в DECISIONS.md.

# VoxFlow v2.3.5 — локальная модель не держит память, пока вы не диктуете

Релиз поверх 2.3.4.

## Выгрузка модели в простое

Локальная модель Ollama раньше висела в памяти постоянно и занимала несколько
гигабайт, даже когда вы ничего не диктовали. На компьютере с 16 ГБ этого
хватало, чтобы вместе с браузером и мессенджерами забить память и своп.

Теперь в разделе ИИ при выборе Ollama есть галочка «Выгружать модель в простое»
и поле «Выгружать через, мин» (по умолчанию 15 минут). Модель выгружается, если
столько времени не было диктовки. Первая фраза после перерыва обработается на
несколько секунд дольше. Снимите галочку - модель будет держаться в памяти всегда,
как раньше.

Подробности - D-052 в DECISIONS.md.

# VoxFlow v2.3.4 — диктовка больше не повторяет уже написанное

Релиз поверх 2.3.3.

## Продолжение текста без повтора

Если в поле уже есть текст и вы диктуете дальше, ИИ-обработка иногда
вставляла прошлую фразу ещё раз вместе с новой: «Удали Ugram и установи
Telegram» → «…и перенеси туда сессию» превращалось в обе фразы целиком.
Теперь повтор уже написанного срезается, а если срезать нельзя - вставляется
распознанный текст без ИИ-правки.

Подробности - D-051 в DECISIONS.md.
