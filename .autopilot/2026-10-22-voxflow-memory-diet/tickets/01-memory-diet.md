# 01 — Модели занимают меньше памяти и выгружаются в простое

**Требования:** R01, R02, R03, R07i
**Зависит от:** —
**Зона:** `voxflow/src-tauri/src/{engine,gigaam,parakeet,vad,settings,local_llm,commands,models,lib,final_eval}.rs` + новый модуль хелпера ORT · `voxflow/src-tauri/Cargo.toml` · `voxflow/src/` · `voxflow/tests/` · `DECISIONS.md`
**Волна:** 1
**Ревью:** да — потеря текста (выгрузка модели рядом с горячим путём диктовки, D-024)
**Модель:** сильная

## Что должно заработать

VoxFlow в диктовке держит модели компактнее, а через 10 минут без диктовки (настраивается) освобождает
модели распознавания и встроенную ИИ-модель. Следующая диктовка грузит модель заново, не теряя ни слова.
В «Моделях» видно, сколько места занимает каждая скачанная модель и какая не используется, удалить можно
кнопкой с подтверждением, и удалённая модель уходит из памяти.

## Из брифа, дословно

> «оптимизируй, пожалуйста, потребление оперативной памяти и вообще памяти, чтобы не так дофига потребляли оперативные приложения, потому что оно потребляет 2 ГБ, это очень много»

Ответы пользователя: «Да, через 10 минут»; «Полную, но ужать»; «Показать размер и кнопку удалить».

## Разделы спецификации

Истории 1-10, «Решения по реализации», границы в `interfaces.md`. Карта кода - `notes.md` (пункты 1-5, 9).

## Как мерить

Замер ДО любых правок, потом после: `#[ignore]`-тест (или скрипт в `tools/`), который с
`VOXFLOW_TEST_DATA_DIR="$HOME/Library/Application Support/VoxFlow"` грузит полную GigaAM (`gigaam-fp32`) и
Parakeet, распознаёт ≥60 записей из `dataset/` и печатает: пиковый и установившийся footprint процесса
(на macOS - `task_info`/`proc_pid_rusage` phys_footprint, не RSS), время энкодера, WER против эталонов,
которыми пользуется `final_accuracy_eval` (если эталонов нет - сравнить тексты до/после побуквенно).
Опцию ORT оставлять, только если память меньше, тексты те же, время не хуже +15%. Цифры до/после - в D-053.

## Критерии приёмки

- [ ] Сессии ORT в gigaam.rs, parakeet.rs, vad.rs создаются одним хелпером с опциями, прошедшими замер
- [ ] Footprint с полной GigaAM + Parakeet после распознавания меньше, чем до (цифры в D-053), тексты на ≥60 записях совпадают с прежними
- [ ] Настройки `asr_unload_idle` (по умолчанию true) и `asr_unload_after_min` (10, clamp 1-1440), старые настройки без полей читаются; галочка и минуты в UI распознавания по образцу Ollama (Ai.tsx)
- [ ] Через N минут без диктовки GigaAM, Parakeet, whisper-server и встроенный llama-server выгружены; во время записи, распознавания и живого превью выгрузка не происходит; юнит-тест на логику простоя без настоящих моделей
- [ ] После выгрузки следующая диктовка работает: загрузка стартует при начале записи, аудио до готовности модели не теряется; тест или замер
- [ ] Footprint в простое после выгрузки на маке ≤ 400 МБ (замер в D-053)
- [ ] Смена языка/движка выгружает модель, которая больше не нужна; `delete_model` выгружает удаляемую модель
- [ ] `list_models` отдаёт `disk_mb` (настоящий размер файлов, null если не скачана) и `in_use` (по текущим настройкам, правила в Rust); тесты в models.rs/commands
- [ ] «Модели»: размер у каждой скачанной, метка «Не используется», удаление с подтверждением, список обновляется после удаления
- [ ] D-053 в DECISIONS.md: что, почему, цифры, отвергнутое
- [ ] `cargo test --locked --lib`, `cargo clippy --locked --all-targets -- -D warnings`, `cargo fmt --check`, `npm run check` зелёные
