# 03 — Подготовка релиза 2.4.0

**Требования:** R04
**Зависит от:** 01, 02
**Зона:** файлы версий из `script/check_versions.py` (как в коммите 1c236ad релиза 2.3.5) · `DECISIONS.md` · `RELEASE_NOTES.md`
**Волна:** 2
**Ревью:** нет
**Модель:** обычная

## Что должно заработать

Версия 2.4.0 во всех файлах, заметки релиза по-русски для людей: меньше памяти, выгрузка в простое, размер
моделей и удаление, пакет для Arch. После пуша тега релиз соберётся для Windows, macOS и Linux.

## Из брифа, дословно

> «Оптимизируй и выпусти обновления для всех операционных систем Linux, MC и Windows»

## Разделы спецификации

§6, история 11.

## Критерии приёмки

- [ ] `python3 script/check_versions.py` проходит на 2.4.0 (и с `--tag v2.4.0`)
- [ ] D-054 (пакет Arch, текст из отчёта таска 02) и D-055 (выпуск 2.4.0) в DECISIONS.md
- [ ] Заметки релиза 2.4.0 в `RELEASE_NOTES.md`, как у 2.3.5, без жаргона, с цифрами памяти из D-053
- [ ] `cargo test --locked --lib`, `cargo clippy --locked --all-targets -- -D warnings`, `cargo fmt --check`, `npm run check`, `npm audit --audit-level=high` зелёные
- [ ] Не пушить и не ставить тег
