# VoxFlow - что осталось

Последняя сборка: `.autopilot/2026-10-22-voxflow-memory-diet/` - меньше памяти (во время диктовки ~1,3 ГБ вместо 2,5-3, в простое ~0,1 ГБ), пакет для Arch, релиз 2.4.0.

## Договорились - не пересматривать

- Полная GigaAM (fp32) остаётся основной, её ужимают, а не меняют на int8 - «Полную, но ужать» (22.10)
- Модели выгружаются через 10 минут простоя, галочка и минуты в настройках - «Да, через 10 минут»
- Модели на диске сами не удаляем: в «Моделях» размер, метка «Не используется» и удаление кнопкой - «Показать размер и кнопку удалить»
- Arch - пакет `.pkg.tar.zst` в релизе, без AUR - «Пакет для pacman в релизе»
- Вопросы пользователю - вариантами (AskUserQuestion), писать ответ ему сложно - «задай мне вопрос именно, чтобы я не писал»

## Не доделано

- Дистрибутивы со старой glibc (< 2.38) - пакеты не встанут, onnxruntime требует 2.38 (R05, вне рамок)
- Автообновление deb/rpm - по-прежнему кнопка на страницу релиза
- На Windows веса моделей копируются в память: отображение выключено, потому что `delete_model` удаляет файл до выгрузки; включить - сначала выгружать, потом удалять (`ort_session.rs` `MAP_WEIGHTS`)

## Известные баги

- `engine.rs` прогрев на старте и при Start идёт мимо `spawn_warmup` - без отметки активности
- `engine.rs` `preload_for_dictation` не поднимает whisper-server после выгрузки; `Unneeded` для whisper не учитывает подмену `resolve_model` (в отличие от `mark_in_use`)
- Первая диктовка после выгрузки: живое превью появляется только после догрузки модели (финал полный)
- Parakeet без prepacking медленнее на 13-15% (en/авто)
- `ort_session.rs:100,108,163` - переполнение длины на заведомо битом файле даёт вылет, а не ошибку (до разбора файл проверяется по SHA-256)
- Отображение весов не сверено 60/60 на int8 GigaAM и VAD; холодный кэш после простоя не мерили
- Arch: pkexec и `pacman -Qqo` на живом Arch не проверены; при отказе pkexec показанная команда указывает на файл во временной папке, которую приложение чистит; файл проверяется по SHA в папке пользователя, а ставится от root
- Галочка выгрузки видна только при локальном распознавании, хотя выгружает и встроенную ИИ-модель
