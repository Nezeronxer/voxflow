# Спецификация: новый кружок, живой текст, локальная модель, установка

Бриф: `2026-10-16-brief.md`. Глубина deep. Ответы брифинга (16.10): стиль - «Капсула + живой текст»; модель - «И то, и другое».

## §1 Капсула (R01, R03, R04)
Ориентир (выбран пользователем из примеров R04): Wispr Flow (тёмная капсула, белые полоски по голосу) + Aqua Voice (живой текст).
- Форма: одна тёмная матовая капсула, радиус = половина высоты. Фон ~`rgba(17,17,20,.88)` + `backdrop-filter: blur(20px)`, обводка 1 px `rgba(255,255,255,.08)`, мягкая тень. Тема - всегда тёмная (плашка поверх любых окон).
- Убрать: градиентный орб и его glow, 12 баров, подписи «Слушаю», «Улучшаю текст…», логотип-волну и надпись «— говорить / Авто» в простое.
- Простой (idle): тонкая капсула ~40×10 px, прозрачность ~0,55; при наведении - подсказка «Зажмите <клавиша> — диктовка» (существующий `.aq-tip`), клик/перетаскивание как раньше.
- Запись (rec): капсула ~96×34, внутри 5 белых полосок 3 px с зазором 3 px, высота 4..18 px по громкости (существующий rAF-цикл level, веса центр>края), атака/спад как сейчас.
- Обработка (trans): капсула ~64×34, три точки, по ним пробегает волна яркости ~900 мс. Без текста.
- Подтверждение двойного тапа (latch) и предупреждения (notice): та же капсула, одна строка текста 12-13 px, без эмодзи и «2×»-плашки - короткий текст `latchNotice.message` (по умолчанию «Без удержания»).
- Переходы между состояниями: 180-220 мс ease-out, width/height меняются раз на смену состояния, анимируются transform/opacity (как требует текущий комментарий в Overlay.tsx). `prefers-reduced-motion` - без всплытий и волны, полоски статичны по уровню.

## §2 Появление текста (R02, R03)
- Режим stream: та же капсула растёт по ширине от ~160 до ~420 px, высота 34 px (одна строка); при длинном тексте - две строки, до ~60 px. Слева мини-волна (3 полоски, продолжают реагировать на голос), справа текст.
- Показывается хвост фразы; начало уходит влево/вверх под градиентную маску ~16 px по краю.
- Новые и изменённые слова проявляются: opacity 0→1 + сдвиг 2-3 px + blur 2px→0, 140-180 мс. Совпавший префикс слов не перерисовывается (сохранить `sharedWordPrefix`/`paintWords`).
- Стабильная часть - `#f2f2f5`, изменчивый хвост - `#8a8a93`, переход в белый ~200 мс.
- Бейджи «офлайн» и язык (RU/EN) - маленькие приглушённые метки внутри капсулы справа, не наезжают на текст.

## §3 Метка модели (R05, часть «показывать»)
- Во время rec/stream/trans в капсуле справа мелкая приглушённая метка активной модели: `GigaAM`, `Parakeet`, `Whisper`; для облака - `Облако`. Нет данных от бэкенда - метки нет.
- Языковой бейдж и метка модели не дублируют друг друга по месту: одна строка «GigaAM · RU».

## §4 Самовыбор установленной локальной модели (R05, часть «определял»)
Сейчас: `ensure_default_models` качает модель по умолчанию, если именно настроенной нет, даже когда другая годная уже лежит в `models/`; `local_route` идёт на Whisper при `language=auto`, а `resolve_model` берёт самый большой .bin только в момент распознавания.
Нужно, при `stt_provider = "local"`:
- На старте и после смены языка/движка: если модели настроенного маршрута нет, но установлена другая локальная, способная распознать этот язык (`ru` - GigaAM fp32 > GigaAM int8 > Whisper; `en` - Parakeet > Whisper; `auto`/смесь - Whisper самая большая валидная, GigaAM как сейчас для auto+gigaam), - использовать её и ничего не качать. Качать по умолчанию - только если для языка нет ни одной установленной.
- Если настроенный `settings.model` (Whisper) отсутствует, а есть другая валидная `.bin` - записать её в настройки (чтобы UI показывал правду) и не качать.
- Облако не включается само; явно выбранное пользователем облако не трогается.
- Без модели вообще - прежнее поведение (`no_model`, загрузка рекомендованной).
- Тесты: чистая функция выбора (вход: язык, движок, набор установленных; выход: маршрут/модель или «качать X») с юнит-тестами на каждый случай выше.

## §5 Установка без повторных разрешений (R06, R07)
- Собрать `.app` локально `./script/build_and_run.sh` или релизным скриптом с `VOXFLOW_SIGNING_IDENTITY="VoxFlow Self-Signed"` - тем же leaf-сертификатом, что у стоящей 2.3.1 (designated requirement `certificate leaf = H"91665ee0…"`).
- Перед заменой сверить designated requirement новой сборки со старой; не совпал - не ставить, сказать пользователю.
- Закрыть запущенный VoxFlow, заменить `/Applications/VoxFlow.app`, запустить. Версия остаётся 2.3.1 (версии меняются только шагом релиза) - это локальная сборка.
- Проверка: `codesign --verify --deep --strict`, `codesign -dr -` совпадает со старым, приложение стартует.
