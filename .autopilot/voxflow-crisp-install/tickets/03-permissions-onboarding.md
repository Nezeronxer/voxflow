## Что должно заработать

Сейчас (разведка): при запуске Rust сам по очереди дёргает системные запросы Мониторинга ввода и Универсального доступа и открывает настройки, показывая только тост ошибки без кнопок; микрофон запрашивается неявно через cpal только при первой диктовке и только если Универсальный доступ уже есть; экрана со статусом нет, `macos_permissions` не выставлен командами Tauri. Нужно: в окне приложения одна карточка «Доступы» с тремя строками - Микрофон, Универсальный доступ (вставка текста), Мониторинг ввода (горячая клавиша) - у каждой живой статус (выдано/нет) и кнопка «Разрешить»/«Открыть настройки»; микрофон запрашивается явно системным окном (AVCaptureDevice requestAccessForMediaType через objc/FFI, если зависимость уже есть в Cargo.lock; иначе - открыть `x-apple.systempreferences:com.apple.preference.security?Privacy_Microphone`) и проверяется `authorizationStatusForMediaType`. Карточка видна, только пока чего-то не хватает (и на маке), обновляет статус сама (опрос раз в 1-2 с, пока видна), исчезает, когда всё выдано, и появляется снова, если доступ отозвали. Существующий автоматический запуск онбординга при старте не должен спорить с карточкой: системные окна - не больше одного раза на запуск, без бесконечного переоткрывания настроек.
