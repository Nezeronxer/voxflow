## Что должно заработать

Русская диктовка идёт через полную (fp32) GigaAM v3 e2e RNNT из `istupakov/gigaam-v3-onnx` (та же ревизия, что у int8 в `models.rs`): `v3_e2e_rnnt_encoder.onnx` (~885 МБ), `v3_e2e_rnnt_decoder.onnx`, `v3_e2e_rnnt_joint.onnx`, общий `v3_e2e_rnnt_vocab.txt`. SHA-256 - из HF API (`/api/models/istupakov/gigaam-v3-onnx/tree/<ревизия>`, поле `lfs.oid`); уже скачанные и сверенные копии для локальной проверки лежат в `~/Library/Caches/voxflow-eval/fp32` (их можно использовать для тестов, в боевую папку не копировать вручную).

Замер D-038 (110 записей, псевдоэталон Whisper large-v3): int8 18,60%, fp32 18,21% - лучше во всех группах длины, время финала на 10-с фразе 165 мс против 182 мс. `gigaam.rs` уже умеет `load_files(dir, threads, &Files)`, `FP32_FILES` сейчас под `cfg(test)` - сделай боевым.

Поведение:
- Новая запись каталога (`DirModel`) «GigaAM-v3 полная - точнее (885 МБ)» со своей папкой (не смешивать с int8), с проверкой SHA-256 и докачкой, как у остальных.
- Скачивается автоматически в фоне (`ensure_default_models` или его аналог) и у новых, и у обновившихся; прогресс виден, как у других моделей.
- Пока fp32 не скачана или не загрузилась - работает int8 без перерыва; при ошибке загрузки fp32 пользователь видит понятное русское сообщение, диктовка не ломается.
- Когда fp32 готова - русская диктовка (финал и живое превью) использует её; в памяти одна загруженная GigaAM, не две. Переключение без перезапуска приложения, если это просто; иначе - со следующего запуска (опиши в CONCERNS).
- int8 не удаляется. Пользователь может вручную выбрать быструю (int8) в каталоге - если выбор модели уже есть в UI; новых экранов не делать.
- Запись D-040 в DECISIONS.md: пользователь решил принять fp32 (цитата), цифры D-038, что с памятью/диском.
