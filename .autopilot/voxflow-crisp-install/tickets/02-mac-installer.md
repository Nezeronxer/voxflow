## Что должно заработать

Человек вставляет в Терминал одну строку `curl -fsSL https://raw.githubusercontent.com/Nezeronxer/voxflow/master/script/install-macos.sh | bash` - и VoxFlow скачивается из последнего релиза GitHub, проверяется по SHA256SUMS, ставится в «Программы» и запускается, без предупреждений macOS (загрузка curl не ставит карантин; на всякий случай `xattr -dr com.apple.quarantine`). README получает понятный первый раздел «Установка на Mac» с двумя путями: команда (рекомендуется) и .dmg (с одним шагом «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть»), плюс «Доступы» (микрофон, Универсальный доступ, Мониторинг ввода выдаются один раз; после обновления до 2.3.0 - последний раз) и обновлённый раздел про подпись (ad-hoc → постоянная самоподпись `signed-unnotarized`; Developer ID - если появится аккаунт Apple). В README же - минимальные версии Linux: glibc 2.38+ (Ubuntu 24.04+, Debian 13+, Fedora 39+, Arch).

macOS-ассет релиза: `VoxFlow-macOS-<версия>-arm64-<метка>.dmg`, где метка - `signed-unnotarized`, `developer-id-notarized` или `adhoc`; скрипт берёт единственный `.dmg` с `-arm64` в последнем релизе. В релизе есть ассет `SHA256SUMS`. Установщик приложения (`apply_downloaded_update` в updater.rs) делает то же через `hdiutil attach -nobrowse -readonly` + `ditto` + переименование - повтори этот приём.

## Критерии приёмки

- [ ] Работает без sudo при записываемой `/Applications`; иначе понятная фраза; Intel-мак, macOS старше минимальной из `tauri.conf.json`, нет сети, не сошлась сумма, нет ассета - останов с русской фразой и ненулевым кодом, установленная версия не тронута
- [ ] Запущенный VoxFlow закрывается (`osascript quit`, затем pkill по имени процесса `voxflow`, ждать выхода), замена атомарная (ditto во временную папку рядом с /Applications → mv), `~/Library/Application Support/VoxFlow` не трогается
- [ ] Повторный запуск: та же версия → «уже последняя» и просто открыть; версия сравнивается по `CFBundleShortVersionString`
- [ ] Переменная `VOXFLOW_VERSION=x.y.z` ставит конкретный релиз (нужно для проверки на старых релизах); `VOXFLOW_DRY_RUN=1` - всё до замены, без замены
- [ ] Проверка: `bash -n`, shellcheck если есть; реальный прогон на этом маке с `VOXFLOW_VERSION=2.1.1 VOXFLOW_DRY_RUN=1` (скачать, сверить сумму, смонтировать, отмонтировать) - не ставить по-настоящему
- [ ] README: раздел установки на Mac первым после краткого описания, без жаргона
