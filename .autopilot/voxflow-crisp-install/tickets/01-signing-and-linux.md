## Что должно заработать

Релизная сборка macOS подписывается постоянным самоподписанным ключом, если в секретах репозитория есть `MACOS_SELF_SIGNED_P12_BASE64` и `MACOS_SELF_SIGNED_P12_PASSWORD`; без них - ad-hoc как сейчас; ветка Developer ID с нотаризацией остаётся и имеет приоритет. Ассеты самоподписи называются `-arm64-signed-unnotarized.dmg/.app.zip` (этот суффикс уже понимают апдейтеры всех установленных версий). Новый скрипт `script/setup-macos-signing.sh` один раз создаёт ключ на маке владельца и кладёт его в секреты GitHub, ни разу не печатая значения. Linux-релиз собирается на ubuntu-24.04, как CI (на 22.04 onnxruntime из ort требует glibc 2.38 и не линкуется - упал релиз v2.2.1).

Известные места, которые ломаются на самоподписи (разведка): `release-macos-arm64.yml` ~L232-235 (p12 без нотаризации отвергается), ~L268-283 (identity обязана начинаться с `Developer ID Application:`), `find-identity -v` фильтрует недоверенный самоподписанный сертификат (нужен `security add-trusted-cert -p codeSign` во временном keychain или поиск без `-v`), `build_macos_arm64_release.sh` ~L531-533 `validate_signing_state` требует TeamIdentifier (у самоподписи `not set`). Проверь, что `tauri build` принимает такую identity и для подписи DMG.

## Критерии приёмки

- [ ] Скрипт setup: openssl-сертификат с EKU codeSigning, CN `VoxFlow Self-Signed`, 10 лет; импорт в login Keychain с доверием для codeSign; `gh secret set` из stdin/файла во временной папке с правами 600, временные файлы удаляются; повторный запуск не плодит второй ключ (находит существующий и спрашивает/выходит с понятной фразой); значения нигде не выводятся
- [ ] Локальная проверка на этом маке: создай ВРЕМЕННЫЙ тестовый сертификат во временном keychain (не login, не секреты GitHub!), собери `script/build_macos_arm64_release.sh` с ним (или минимально - подпиши две сборки .app), и докажи: `codesign -d -r-` двух последовательных сборок совпадает, `codesign --verify --deep --strict` проходит, имя ассета `-signed-unnotarized`; временный keychain удалён
- [ ] Workflow: режим «p12 без нотаризации» → подпись самоподписью, без нотаризации; Developer ID с полным набором - как раньше; без секретов - ad-hoc; ни один путь не печатает секреты
- [ ] release-linux.yml на ubuntu-24.04; проверка `actionlint`, если есть, иначе python-yaml парс всех workflow
- [ ] `bash -n` (и shellcheck, если установлен) на изменённых скриптах зелёные
