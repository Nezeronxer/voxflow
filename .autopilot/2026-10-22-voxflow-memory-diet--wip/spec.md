# Спецификация: VoxFlow ест меньше памяти, релиз 2.4.0 для всех ОС

## Задача
«Оно потребляет 2 ГБ, это очень много». Замер на маке 22.10: footprint процесса `voxflow` 2401 МБ, из них
2229 МБ - модели распознавания (Malloc Large). Язык «авто», поэтому в памяти сразу полная GigaAM (fp32, 885 МБ
на диске) и Parakeet (652 МБ). Модели не выгружаются никогда, даже удалённые с диска. На диске моделей ~6 ГБ,
из них Whisper large-v3 3,1 ГБ не используется.

## Решение
1. Сами модели держатся в памяти компактнее: опции onnxruntime, которые не копируют веса (prepacking,
   memory pattern, arena). Принимается только то, что доказано замером: память меньше, точность та же,
   время распознавания не хуже чем на 15%.
2. После 10 минут без диктовки модели распознавания (GigaAM, Parakeet, whisper-server) и встроенная
   ИИ-модель (llama-server) выгружаются. Галочка и минуты в настройках распознавания, как у Ollama в D-052.
   Следующая диктовка грузит модель заново; загрузка начинается при нажатии клавиши, пока человек говорит.
3. Удалённая модель уходит и из памяти; смена языка/движка выгружает модель, которая больше не нужна.
4. В «Моделях» у каждой скачанной модели - настоящий размер на диске и метка «Не используется», если
   при текущих настройках она не нужна; удаление кнопкой с подтверждением. Сами ничего не удаляем.
5. Для Arch в релизе пакет `VoxFlow-X.Y.Z-linux-x64.pkg.tar.zst` (`sudo pacman -U`), встроенное обновление
   на Arch его выбирает и ставит через `pkexec pacman -U`; без polkit - показывает команду.
6. Релиз 2.4.0: Windows, macOS, Linux (AppImage, deb, rpm, pacman). Пуш и тег - только после «да» пользователя.

## Решения по реализации
- Опции ORT ставятся в одном общем хелпере, которым пользуются gigaam.rs, parakeet.rs, vad.rs - чтобы три места не разошлись.
- Таймер простоя - поток в engine.rs, отметка последней активности; ORT/whisper-сервер освобождаются заменой на `None`/kill.
- `in_use` и размер на диске считает Rust (`list_models`), фронт только показывает - правила маршрута живут в одном месте (`local_route_with_parakeet`, `gigaam_variant`).
- Пакет Arch собирается из готового deb отдельной job/шагом в контейнере `archlinux:latest` через `makepkg` (Tauri 2 не умеет pacman).
- Установка на Arch - `pkexec pacman -U --noconfirm`; deb/rpm остаются как были (кнопка ведёт на релиз).
- Решения с неочевидной причиной - D-053 (память/выгрузка), D-054 (пакет Arch), D-055 (релиз 2.4.0).
