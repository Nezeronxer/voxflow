# Проверка VoxFlow 2.4.7

Дата: 2026-11-02. Нативная Linux-сборка из исходников релиза, отдельные Xvfb/Openbox, D-Bus и каталог данных. Изолированный аудиовход PulseAudio; личный микрофон не использовался. Пользовательские настройки и история не менялись.

## Результаты

| Сценарий | Результат |
|---|---|
| OpenRouter без API-ключа | Публичный каталог: 373 текстовые модели; нативный список открывается |
| Выбор мышью и клавиатурой | Выбранная модель записана в SQLite и восстановлена после перезапуска |
| Нет сети / недоступный прокси | Сообщение об ошибке, встроенный список остаётся доступным |
| «Обновить список» | Повторный запрос; после восстановления ответа каталог обновляется |
| Медленный ответ, выбор во время загрузки | Выбор сохраняется после ответа |
| Пустой ответ каталога | Встроенный список и ранее выбранная модель остаются доступны |
| Ошибка выбранной модели при «Проверить» | Каталог показывается, выбор не сбрасывается |
| «Проверить» без ключа | Понятный отказ; список продолжает работать |
| Окна 1180×760 и 720×520 | Список и повторная загрузка доступны; кнопка не сжимает поле |
| Словарь | Пустое состояние, добавление и удаление тестовой записи; сохранение в базе |
| История и каталог локальных моделей | Экраны открываются; история диктовки сохранена, скачанные модели видны |
| Диктовка, локальная GigaAM | Горячая клавиша → виртуальный аудиовход → распознавание → 142 символа в настоящем Gtk.TextView; текст совпадает с историей |
| Отмена диктовки | После Escape текст в поле не появляется |
| X11 без менеджера буфера | Воспроизведена потеря clipboard; после исправления независимый читатель и поле ввода получают текст |

Ошибки/пустой ответ/медленный ответ каталога воспроизведены отдельно на настоящем React-компоненте в Chrome с тестовым IPC. Работа с настоящим каталогом, офлайн-список, выбор, сохранение и диктовка проверены в нативном приложении.

## Автоматические проверки

- Node: 54 пройдено, включая рендер настоящего компонента до загрузки каталога.
- TypeScript + Vite: успешно. npm audit: 0 уязвимостей.
- Rust: 441 пройдено; 21 тест с внешними фикстурами/специальной средой пропущен обычным прогоном.
- Отдельно запущены и пройдены сетевой тест публичного каталога без действительного ключа и X11-тест времени жизни clipboard.
- cargo clippy all-targets с -D warnings; cargo fmt --check; проверка версий.
- Регрессии выбора модели, формата architecture.output_modalities и clipboard сначала падали на старой реализации, затем прошли после исправления.

## Воспроизведение

```sh
npm --prefix voxflow run check
npm --prefix voxflow audit --audit-level=high
TAURI_CONFIG='{"bundle":{"resources":[]}}' cargo test --locked --manifest-path voxflow/src-tauri/Cargo.toml --lib
TAURI_CONFIG='{"bundle":{"resources":[]}}' xvfb-run -a cargo test --locked --manifest-path voxflow/src-tauri/Cargo.toml --lib native_clipboard_owner_survives -- --ignored
python3 script/check_versions.py --tag v2.4.7
```

Для обновления встроенного каталога: `python3 script/update_openrouter_catalog.py`. Используется публичный OpenRouter `/models`, ключ не передаётся. В окружении без прямого доступа можно задать стандартный HTTPS_PROXY.

## Границы проверки

Нативные окна Windows и macOS на Linux не запускались: их компиляция, тесты и упаковка проверяются отдельными CI jobs. Wayland-плашка не менялась этим исправлением; её события и геометрия покрыты существующими регрессиями. Живые платные запросы ко всем моделям OpenRouter не выполнялись. Это отчёт о перечисленных проверках, а не гарантия отсутствия всех возможных дефектов.
